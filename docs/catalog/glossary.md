# Glossary: one word per thing

Status: **draft, 2026-11-14.** Both apps and every issue use the word in the first column. Where an
app's label differs today it is listed, and that app changes at its next release unless the row
says otherwise. Add a row whenever two words for one thing turn up.

| Use this | Means | Computer says today | Phone says today |
| --- | --- | --- | --- |
| Date added | library sort by when a manga was added | "Date added" (from 0.1.14) | "Date added" |
| Last read | library sort by when any chapter of a manga was last read | "Last read" (from 0.1.14) | "Last read" |
| Latest chapter | library sort by the upload date of a manga's newest chapter | "Latest chapter" (from 0.1.14) | to be confirmed |
| Pick / picked | manga or chapters marked for one action on all of them (Ctrl/Shift+click) | "N picked" | long-press selection |
| Genre | a tag a source gives a manga; the library filters by it | "Genres" filter, pills on the manga page | to be confirmed |
| Library | one profile's manga and reading state | Library | Library |
| Profile | a separate library with its own settings | Profile | "profile name" on the LAN sync screen |
| Link / linked device | two devices that exchanged a key | "Linked devices" | "Linked devices", "Link to computer" |
| Pairing code | the six digits used once to link | Pairing code | Pairing code |
| Sync | the linked devices bringing each other up to date | "Sync" screen; today it only copies once | "LAN sync" (a switch, no action) |
| Leader / follower | in one-way sync, whose changes are sent / who receives | not built | not built |
| Remote storage | the WebDAV server (a NAS) that holds chapters, and later the sync state | "NAS storage" (to change) | to be confirmed by the phone side |
| Download queue | chapters waiting to download | Downloads | to be confirmed |
| On server / On <device> | where a chapter is, other than this device | cloud mark, "On the NAS" | to be confirmed |

Rows marked "to be confirmed" are filled in by the phone-app session from what its screens say.
