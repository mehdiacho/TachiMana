§0 · How to read this spec
Every dimension is one of three kinds. (a) Density — type, radii, strokes, icons, padding, gaps, fixed heights: fixed density units (px at 1× / dp), never scaled by window width. (b) Width-class — the short §1.6 whitelist that tracks available width via size-class breakpoints. (c) Vertical position — never coordinates: every screen is an ordered flex stack of fixed/intrinsic blocks with exactly one flexible spacer (flex:1) per region. Baseline reference window: 1440×900 (design mockups shown at 1240 wide); minimum window 1024×640.
Key point: anything not listed in §1.6 is fixed. When unsure, it is density, not width-class.
